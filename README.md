# مستشار البورصة المصرية (EGX Stock Advisor)

تطبيق ويب ذكي ومتكامل لمتابعة وتحليل أسهم البورصة المصرية (EGX) بالاعتماد على الذكاء الاصطناعي (نماذج Google Gemini) والمؤشرات الفنية اللحظية، مع نظام تقييم زمني تراكمي ومزامنة سحابية مزدوجة مع **Google Sheets**.

---

## 🌟 الميزات الرئيسية

### 1. بيانات السوق اللحظية والفنية (Market Data Engine)
* **دمج ذكي للأسعار:** يجمع بين البيانات التاريخية لعام كامل من Yahoo Finance والأسعار واللقطات اللحظية المباشرة من TradingView Egypt Scanner.
* **مؤشرات فنية دقيقة:** حساب تلقائي لمؤشرات القوة النسبية (RSI)، المتوسطات المتحركة (SMA 20, 50, 200)، حدود بولينجر (Bollinger Bands)، ومعدل التذبذب اليومي (ATR).
* **تحديد الدعوم والمقاومات:** استخراج مستويات الدعم والمقاومة التاريخية واللحظية تلقائياً.

### 2. محرك الأخبار الذكي (Smart News Aggregator)
* جلب أحدث الأخبار من Google News RSS باللغتين العربية والإنجليزية.
* فلترة وتصفية الأخبار بناءً على كود السهم واسم الشركة بالعربية والإنجليزية لتجنب الأخبار غير ذات الصلة.

### 3. تحليل الذكاء الاصطناعي المنظم مع نظام التبديل التلقائي (Gemini AI Cascade)
* **قواعد مالية صارمة:** إجبار النموذج عبر Pydantic Structured Output على احترام القواعد الرياضية للمضاربة والاستثمار (عدم تجاوز وقف الخسارة لسعر الدخول في الشراء، والعكس في البيع).
* **التوثيق المرجعي للأسباب:** إلزام النموذج بربط كل حيثية في قراره برمز المؤشر الفني `[IND:...]` أو الخبر الصحفي `[NEWS:...]`.
* **التبديل التلقائي الذكي بين النماذج (Fallback Cascade):**
  يبدأ التحليل بنموذج `gemini-3.8-flash`، وفي حال حدوث ضغط على الخوادم (503) أو نفاد الحصة المجانية اليومية (429 Quota Exceeded)، ينتقل التطبيق تلقائياً وبسلاسة إلى نماذج الفلاش الخفيفة السريعة (`gemini-3.5-flash-lite` ثم `gemini-3.1-flash-lite` ثم `gemini-3.5-flash`) لضمان استمرار عمل التطبيق دون توقف.

### 4. نظام المتابعة اللحظية وتقييم دقة التوصيات (Real-time Tracker)
* **تقييم أداء فوري:** بضغطة زر واحدة `🔄 تحديث تقييم التوصيات الآن`، يقوم النظام بفحص الأسعار اللحظية لجميع التوصيات وحساب:
  - السعر اللحظي الحالي لكل سهم.
  - العائد اللحظي/المحقق (Return %).
  - حالة التوصية (مستمرة قيد المتابعة / ناجحة حققت الهدف / فاشلة ضربت وقف الخسارة).
* **إحصائيات النجاح (Win Rate):** احتساب نسبة نجاح التوصيات ومتوسط العائد اللحظي وإجمالي التوصيات النشطة والمنتهية.
* **عرض منظم ومتجاور:** ترتيب الأعمدة في الجدول الرئيسي ليكون `[سعر الدخول] | [السعر اللحظي/الحالي] | [العائد اللحظي/المحقق %] | [تاريخ ووقت التحديث اللحظي]` بجوار بعضها مباشرة لسهولة المتابعة الفورية.

### 5. نظام التخزين السحابي المزدوج (Dual Google Sheets Architecture)
* **الورقة الأولى (`Sheet1`):** جدول التوصيات الرئيسي؛ يتم تحديث نفس سطر السهم بأحدث سعر وعائد وتوقيت فحص دون تكرار.
* **الورقة الثانية (`snapshots_log` - أرشيف المتابعات اللحظية):** سجل تدقيق تراكمي (Audit Log)؛ يُسجل سطراً جديداً مستقلاً لكل سهم في كل ضغطة تحديث متضمناً الطابع الزمني بالثانية بتوقيت القاهرة وسعر تلك اللحظة والعائد والحالة.
* **عرض الأرشيف في التطبيق:** نافذة منسدلة مدمجة `📜 أرشيف المتابعات اللحظية المتتالية` لاستعراض السجل الزمني التراكمي مباشرة.
* **نسخ احتياطي محلي تلقائي (Local CSV Fallback):** في حال حدوث أي انقطاع في الاتصال بجوجل، يعمل التطبيق بسلاسة على ملفات CSV محلية.

### 6. حماية وأمان (Security Gate)
* بوابة تسجيل دخول بكلمة مرور (`APP_PASSWORD`) لحماية واجهة التطبيق، استهلاك واجهة برمجة تطبيقات Gemini، والاطلاع على التوصيات وسجلات التتبع.

## 🛠️ خطوات الإعداد والنشر (Streamlit Cloud)

### 1. إعداد Google Cloud & Google Sheets
1. ادخل إلى [Google Cloud Console](https://console.cloud.google.com/) وأنشئ مشروعاً جديداً.
2. فعّل مكتبتي **Google Sheets API** و **Google Drive API** من قائمة APIs & Services.
3. أنشئ **Service Account**، ثم من تبويب **Keys** اختر **Add Key > Create new key (JSON)** وحمّل الملف لجهازك.
4. افتح [Google Sheets](https://docs.google.com/spreadsheets) وأنشئ جدول بيانات جديداً.
5. اضغط على **مشاركة (Share)** وأضف البريد الخاص بالـ Service Account (الموجود في ملف JSON تحت `client_email`) بصلاحية **محرر (Editor)**.
6. انسخ معرّف الشيت (Sheet ID) من رابط الصفحة (النص الموجود بين `/d/` و `/edit`).

### 2. إعداد الأسرار (`secrets.toml`)
أنشئ ملف `.streamlit/secrets.toml` محلياً (أو في إعدادات Secrets على Streamlit Cloud):

```toml
# كلمة المرور لحماية التطبيق
APP_PASSWORD = "your_secure_password"

# مفتاح Gemini API من Google AI Studio
GEMINI_API_KEY = "your_gemini_api_key"

# معرّف ملف Google Sheets
GSHEET_ID = "your_google_sheet_id_here"

# تفعيل البحث الحي عبر جوجل في النموذج (يتطلب حساب مدفوع في AI Studio)
USE_SEARCH_GROUNDING = false

# بيانات حساب الخدمة (Service Account) من ملف الـ JSON
[gcp_service_account]
type = "service_account"
project_id = "your-project-id"
private_key_id = "your-key-id"
private_key = "-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n"
client_email = "your-sa@your-project.iam.gserviceaccount.com"
client_id = "..."
auth_uri = "https://accounts.google.com/o/oauth2/auth"
token_uri = "https://oauth2.googleapis.com/token"
auth_provider_x509_cert_url = "https://www.googleapis.com/oauth2/v1/certs"
client_x509_cert_url = "..."
universe_domain = "googleapis.com"
```

### 3. النشر على Streamlit Cloud
1. ارفع الكود إلى مستودع GitHub خاص أو عام (ملف `.gitignore` مهيأ لحجب مفاتيح الأسرار والملفات الحساسة تلقائياً).
2. ادخل إلى [share.streamlit.io](https://share.streamlit.io/) واختر المستودع والفرع `main`.
3. اضغط على **Advanced Settings**، ثم في خانة **Secrets** الصق محتوى ملف `secrets.toml` كاملاً.
4. اضغط **Deploy**.

## 💻 التشغيل المحلي والتطوير

```bash
# إنشاء بيئة عمل افتراضية وتفعيلها
python -m venv venv
.\venv\Scripts\activate   # على Windows
# source venv/bin/activate # على Linux/Mac

# تثبيت المكتبات المطلوبة
pip install -r requirements.txt

# تشغيل التطبيق
streamlit run app.py
```
